# User Journeys

## J1 — First run (Onboarding)

1. Open app. Philosophy in three short screens: "Not anti-AI", "Dependency is
   behavior, not time", "Your data stays on your device".
2. Optional: pick 2-3 capabilities to focus on (defaults provided).
3. Land on Home with Brain Score in a neutral starting state and today's
   challenge visible. No account. No permissions requested.

Emotional goal: curiosity and safety, zero judgment.

## J2 — The gate moment (AI Gate)

1. User is about to ask AI something; opens Human Mode and taps "AI Gate"
   (MVP is self-directed; OS-level interception is post-MVP).
2. Gate asks: *What are you about to ask AI?* (one line, local only) and
   *Have you tried it yourself yet?*
3. If not tried: offers a 3-minute "attempt first" timer (skippable — the
   Proceed to AI button is always available, without guilt copy).
4. After attempt: *Solved it yourself / Want a hint / Proceed to AI.*
5. Outcome recorded as a usage event; optional one-tap reflection.

Emotional goal: a calm pause, not a barrier. The gate never says no.

## J3 — Daily practice (Challenge -> Reflection)

1. Home shows today's challenge (deterministic per day, adapted difficulty).
2. User reads instructions, does the work *outside or inside the app*
   (a text field is provided for writing-type challenges; content stays local).
3. Marks the outcome honestly: Completed / Attempted / Skipped.
4. Two reflection questions; one-line answers, optional.
5. Result screen: quiet affirmation, XP recorded, streak updated.

Emotional goal: "I did real thinking today."

## J4 — Focus block (Detox Mode)

1. User picks a duration (25/50/90 min) and an intention ("draft the memo myself").
2. Timer runs; app stays out of the way.
3. Session ends: completed or ended early — both recorded neutrally.
4. Optional reflection: "What did you notice?"

Emotional goal: spaciousness. Ending early is data, not defeat.

## J5 — Understanding myself (Brain Report / Progress)

1. User opens Brain Report: dependency score with per-factor breakdown and
   plain-language explanation of *why* it is what it is.
2. Progress shows challenge history, capability spread, streak, XP —
   additive framing only.

Emotional goal: insight, agency, transparency (never a verdict).

## J6 — Leaving (the healthy exit)

1. Months later the user opens the app rarely; behavior has changed.
2. Progress explicitly frames this as success ("needing this less is the point").
3. Settings offers full data export and full deletion, both one tap.

Emotional goal: graduation, not churn.
