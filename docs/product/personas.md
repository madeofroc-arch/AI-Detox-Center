# Personas

Target users share one trait: they *use AI heavily and want to keep using
it* — but have noticed their own thinking atrophy and want it back.

## 1. Devin — the AI-native developer (27)

- Uses coding agents all day; ships fast.
- Notices: can no longer start a design from a blank page; reaches for AI at
  the first compiler error; anxiety when the AI service is down.
- Wants: to keep AI for leverage but rebuild first-attempt muscle.
- Key features: AI Gate (attempt-first timer), Problem Solving and Focus
  challenges, dependency breakdown ("lack of attempt" factor).

## 2. Mei — the graduate student (24)

- Writes papers with AI assistance; summarizes readings with AI.
- Notices: hasn't formed her own argument in months; every paragraph starts
  in a chat box; asks AI to double-check things she already knows.
- Wants: to write and reason independently again, use AI as reviewer not author.
- Key features: Writing and Thinking challenges, "review my own work first"
  usage category, reflection.

## 3. Alex — the product manager (35)

- Uses AI for every email, decision memo, and prioritization call.
- Notices: outsourcing judgment; asks AI to decide, then asks again for
  reassurance.
- Wants: to make decisions and communicate in their own voice.
- Key features: Decision Making and Communication challenges, "decision
  outsourcing" and "reassurance seeking" tracking, Brain Report.

## 4. Sam — the mindful self-improver (30)

- Not a heavy professional AI user, but feels the pull; values focus and
  digital well-being; privacy-conscious.
- Wants: a calm daily practice, not another engagement app; data stays local.
- Key features: Daily Challenge, Detox Mode, Progress, strict local-first
  privacy.

## Explicit non-targets

- People seeking clinical treatment for addiction (we are not a medical product).
- Organizations wanting to surveil employees' AI usage (we will not build this).
- Users wanting a hard blocker/parental-control tool.
