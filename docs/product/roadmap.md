# Roadmap

## Phase 1 — Foundation (current)

- Skill-driven development system (5 skills)
- Product, design, and architecture documentation
- `@ai-detox/core`: scoring, gate, detox, tracking, reflection, challenges,
  local storage — deterministic and unit-tested
- Expo app with the 10 MVP screens
- OSS scaffolding + CI

## Phase 2 — Depth

- Expanded challenge catalog (community-contributed, curated)
- Richer Brain Report (trends over time, factor history)
- Gentle habit scaffolding (time-of-day suggestion, still no push pressure)
- More languages (English and zh-TW ship today; adding one is a data change,
  see CONTRIBUTING.md)
- Component/UI test coverage

## Phase 3 — Integration (all opt-in, all local-first)

- OS-level assist: shortcuts/share-sheet entry into AI Gate
- Browser extension prototype for gate-before-chat
- Optional local AI usage classification (on-device or user-keyed API;
  never in the scoring path, classification only)

## Phase 4 — Community & sustainability

- Plugin interface for community challenge packs
- Optional encrypted sync (explicit opt-in, E2E, self-hostable)
- Monetization exploration — constraint: never ads, never data sales,
  never pay-to-win mechanics. Candidates: donations/sponsorship,
  paid convenience (sync hosting), pay-what-you-want.

## Standing constraints (never on any roadmap)

Surveillance features, engagement-maximizing mechanics, default cloud
storage of personal thought data, social comparison.
