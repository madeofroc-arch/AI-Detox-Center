# Human Mode

Answers that rebuild your thinking instead of replacing it.

Instead of handing over a finished answer by default, this skill responds on a
hint ladder: orient, nudge, hint, approach, full answer. Conversations start
part-way up and descend whenever you ask for more.

**It never locks.** "Just give me the answer" works instantly, and it skips the
ladder on its own when something is urgent, when the question is pure lookup,
when the work is mechanical, or when you have already shown your reasoning.

Full install instructions for Claude Code, Codex, Cursor, claude.ai, ChatGPT and
Gemini — plus how to improve the teaching method itself — are in
[skill/README.md](../../skill/README.md).
